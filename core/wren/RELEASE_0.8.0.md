# Wren 0.8.0

Released: 2026-07-23

This release metadata was recovered from `release-please--branches--main--components--wren` and preserved on canonical `main` during the branch-extinction sweep.

## Breaking change

- Rename the PyPI package from `wren-engine` to `wrenai`.

## Major capabilities represented in the release

- MDL layout versioning and dialect fields on Model and View.
- Browser WASM support and full Cube translation support.
- Named connection profiles, environment-driven secrets, and automatic connection validation.
- LanceDB-backed schema/query memory with list, forget, dump, and load commands.
- Standalone Wren Python SDK and expanded CLI behavior.
- MySQL auto-discovery, connection documentation, SQL identifier-case fixes, and CTE planning improvements.
- Oracle connector, access-control, security dependency, and documentation fixes.
